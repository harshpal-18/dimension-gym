Dimension Gym 🏋️‍♂️

A modern full-stack gym management and fitness platform built with React, Node.js, Express, MongoDB, Razorpay, Vercel, and Render.

🚀 Live Demo

🌐 Frontend:
Dimension Gym Live Website: https://dimension-gym.vercel.app

📂 GitHub Repository:
Dimension Gym GitHub Repo: https://github.com/harshpal-18/dimension-gym.git

🧑‍💻 Installation
Clone Repository
git clone https://github.com/harshpal-18/dimension-gym.git
cd dimension-gym
▶️ Frontend Setup
npm install
npm run dev

Runs on:

http://localhost:5173
▶️ Backend Setup
cd server
npm install
npm start

Runs on:

http://localhost:5000
